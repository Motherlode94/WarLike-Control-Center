    Contrôles indispensables avant connexion

    Authentification : WarLike Keys et sessions de WarLike Server, avec rôles et permissions distincts.

    Secrets : jetons API uniquement côté serveur, jamais dans le HTML, le localStorage ou GitHub.

    Exécution : aucun script arbitraire, listes d'outils autorisées, limite de dépenses et quotas par fournisseur.

    Approbation : confirmation explicite avant fusion, déploiement, suppression ou dépense.

    Traçabilité : journal D1 horodaté des demandes, exécutions, erreurs et actions autorisées.

    Réseau : appels API externes côté backend, contrôle des origines et vérification de signature des webhooks.

    Version initiale · Interface statique de cadrage · L'activation des intégrations nécessite des adaptateurs côté WarLike Server.
